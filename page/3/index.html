🕐 2026.03.11 — 2026.03.14 ｜ 实习第一周 🏠 关于租房入职前两天线下看房找房，真的把自己累得不轻。 跑了好几个地方，最后机缘巧合在闲鱼上刷到一个帖子——一个中介自己住的房子在找合租室友。说实话，刚开始真以为是中介冒充房东的老套路，反复确认之后才发现，是一群做中介的年轻人合租在一起，刚好空出来一间。 750/月，房间不大，但够住，性价比还算可以。 算是在兵荒马乱里，落了个脚。 💼 关于工作目前还算轻松，节奏比想象中舒服不少。 公司很喜欢用 Claude Code 干活——经常就是敲完指令，两手一摊，好不悠闲。研发部和总部不在一起办公，平常管理也不算严苛，没什么条条框框的束缚感。 前辈们都很年轻，沟通起来没有距离感，这一点挺好的。 虽然是 996，但目前的工作强度还在舒适区内。 💭 碎碎念 实习第一周，忙碌但新鲜。希望这份工作的悠闲，能一直持续到我离职那天吧。 ✨ 新城市、新住处、新工作——一切都在慢慢步入正轨。

发表于2026-03-08|微光拾级
因为明天充满了太多未知，而那些未知远远超过我曾经经历过的一切。 忙碌了一周，终于偷得半日空闲，匆匆从零开始搭起这个博客。只是想给未来的自己留下一些可供回想的片段，让那些记忆，不被流星带走。 这段时间为了找实习，向很多哥哥们请教、求助。简历前前后后修改了整整十版（哎哎）。投出了大概一百二十份简历之后，终于收到了第一份 offer。那一刻其实没有想象中的狂喜，更多的是一种松了一口气的疲惫感。 如今再回头看，只觉得现在找工作真的不太容易。 明天就要去杭州了。这是我第一次一个人离开郑州，在一座完全陌生的城市生活。 比起激动，不安似乎在胸腔里占据了更多的位置。未知，距离，孤独，未来，好像都在这一刻一起涌了上来。 但无论如何—— 明天见。
